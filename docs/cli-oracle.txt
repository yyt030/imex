## export
Export data from a MySQL or OceanBase database to a DEL (delimited ASCII),
SQL, or Parquet format file.

Examples:
  # Basic export to DEL format
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.del -q "SELECT * FROM users"

  # Export to SQL format
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.sql -f sql -q "SELECT * FROM users"

  # SQL export carries data only; get the table definition from show
  imex show tab users -D mydb -o /backup/users_ddl.sql

  # Read the query from a file instead of the command line
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.sql -f sql -q @/backup/users_query.sql

  # Export to Parquet format
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.parquet -f parquet -q "SELECT * FROM users"

  # Parallel export with 4 threads
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.del --threads 4 -q "SELECT * FROM users"

  # Custom delimiters
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.del --char-del '!' --col-del '@' \
    -q "SELECT * FROM users"

Usage:
  imex export [flags]

Aliases:
  export, exp

Flags:
      --batch-size int                  Rows per hand-off batch; with --threads>1 it is a usage error (default 1000)
      --char-del string                 String delimiter (only with --format del) (default "\"")

      --connect-timeout duration        TCP connect timeout (default 5s)
  -D, --database string                 Database name (also IMEX_DATABASE)

      --engine string                   Database engine: mysql, pg, dm (default "mysql")
      --escape string                   Escape character (only with --format del) (default "\"")
      --extended-insert                 Merge rows into multi-row INSERTs (only with --format sql)
  -f, --format string                   Output file format (del/sql/parquet) (default "del")
  -?, --help                            help for export
      --hex-blob                        Binary columns as 0x hex literals (not with --format parquet)
  -h, --host string                     Database host address (also IMEX_HOST) (default "127.0.0.1")
      --log-level string                Log level (debug/info/warn/error) (default "info")
  -m, --messages string                 Redirect the command log to this file; with it, nothing is printed to stderr
      --no-char-del                     Do not use string delimiter (only with --format del)
      --no-col-names                    Do not output column names (only with --format del)
      --no-escape                       Disable escaping (only with --format del)
      --no-hex-blob                     Force raw binary passthrough (may corrupt data) (not with --format parquet)
      --no-overwrite                    Refuse to overwrite an existing output file (default: overwrite)
  -o, --output string                   Output file path (required)

  -P, --port int                        TCP/IP port (also IMEX_PORT) (default 3306)
      --progress-interval duration      Periodic progress log interval (min 100ms) (default 5s)
  -q, --query string                    SQL SELECT statement, or @file to read it from a file
      --row-del string                  Row delimiter (only with --format del) (default "\n")

## import
Import data from a DEL (delimited ASCII), SQL, or Parquet format file into a
MySQL or OceanBase database.

Examples:
  # Basic import from DEL format
  imex import -h 127.0.0.1 -u root -p pass -D mydb \
    -i /backup/users.del -t users

  # Import from Parquet format
  imex import -h 127.0.0.1 -u root -p pass -D mydb \
    -i /backup/users.parquet -f parquet -t users

  # Import with insert_update mode
  imex import -h 127.0.0.1 -u root -p pass -D mydb \
    -i /backup/users.del --mode insert_update -t users

  # Import a SQL dump (any CREATE/DDL lines are skipped; only the INSERT data
  # is loaded, into a table that must already exist)
  imex import -h 127.0.0.1 -u root -p pass -D mydb \
    -i /backup/users.sql -f sql -t users

  imex import [flags]

  import, imp

## show
Show the CREATE statement the server holds for one table, view, trigger,
event, procedure or function.

The definition goes to --output, or to stdout when neither --output nor
--messages is given. With --messages and no --output the log and the definition
share that file and nothing is printed to the screen.

  imex show tab users -D mydb
  imex show vws v_orders -D mydb -o /backup/v_orders.sql

A name may carry its own schema qualifier (mydb.users); otherwise --database
supplies it, so one of the two is required. Batches come from `imex list`.

Usage:
  imex show [flags]
  imex show [command]

Available Commands:
  evt         Show the definition of one event
  fcn         Show the definition of one function
  prc         Show the definition of one procedure
  tab         Show the definition of one table
  trg         Show the definition of one trigger

## root
imex is a table-level MySQL logical backup and restore tool.
It supports both MySQL and OceanBase MySQL mode.

Features:
  - Export data to DEL (delimited ASCII), SQL or Parquet format
  - Import data from DEL, SQL or Parquet format
  - Customizable delimiters and format options
  - Secure password encryption (AES-256-GCM)
  - Command log file (--messages)
  - Multiple import modes (insert, insert_update, replace)
  - Parallel export/import with pipeline optimization
  - Column mapping for flexible data import
  - Smart JOIN detection for parallel export

Usage:
  imex [command]

Available Commands:
  encrypt     Encrypt password for secure automation
  export      Export data from MySQL/OceanBase
  help        Help about any command
  import      Import data into MySQL/OceanBase
  list        List databases and schema objects
  show        Show the definition of one object
  version     Print version information

Flags:
      --echo-sql-values     Echo real row values in failed SQL, not redacted tags (also IMEX_ECHO_SQL_VALUES=1)
      --error-stack         Print full error call stack on failure (also enabled via IMEX_ERROR_STACK=1)
  -h, --help                help for imex
      --log-format string   Log layout: console or text (slog key=value); also IMEX_LOG_FORMAT (default "console")
      --no-sql-tag          Do not prepend the /* imex:<commit> */ comment to statements (also IMEX_NO_SQL_TAG=1)

Use "imex [command] --help" for more information about a command.
