## export
Export data from a MySQL or OceanBase database to a DEL (delimited ASCII),
SQL, or Parquet format file.

Examples:
  # Basic export to DEL format
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.del -q "SELECT * FROM users"

  # Export to SQL format
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.sql -f sql -q "SELECT * FROM users"

  # SQL export is data-only; add --create when the dump must be self-contained
  # (import ... --mode create reads the CREATE TABLE from the file)
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.sql -f sql --create -q "SELECT * FROM users"

  # Read the query from a file instead of the command line
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.sql -f sql --query-file /backup/users_query.sql

  # Export to Parquet format
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.parquet -f parquet -q "SELECT * FROM users"

  # Parallel export with 4 threads
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.del --threads 4 -q "SELECT * FROM users"

  # Custom delimiters
  imex export -h 127.0.0.1 -u root -p pass -D mydb \
    -o /backup/users.del --char-del '!' --col-del '@' \
    -q "SELECT * FROM users"

Usage:
  imex export [flags]

Aliases:
  export, exp

Flags:

      --col-del string                  Column delimiter (only with --format del) (default ",")

      --date-fmt string                 Date format (only with --format del) (default "yyyy-MM-dd")
      --default-charset string          Connection & output-file charset (utf8mb4 default; also utf8, latin1, ascii, gbk, gb18030)
      --escape string                   Escape character (only with --format del) (default "\"")
      --extended-insert                 Merge rows into multi-row INSERT statements bounded by --statement-size (only with --format sql)
  -f, --format string                   Output file format (del/sql/parquet) (default "del")
  -?, --help                            help for export

  -p, --password string                 Database password

## import

MySQL or OceanBase database.

  imex import -h 127.0.0.1 -u root -p pass -D mydb \

  # Import from Parquet format
  imex import -h 127.0.0.1 -u root -p pass -D mydb \
    -i /backup/users.parquet -f parquet -t users

  # Import with insert_update mode
  imex import -h 127.0.0.1 -u root -p pass -D mydb \
    -i /backup/users.del --mode insert_update -t users

  # Create table from SQL file
  imex import -h 127.0.0.1 -u root -p pass -D mydb \

## root
imex is a table-level MySQL logical backup and restore tool.
It supports both MySQL and OceanBase MySQL mode.

Features:
  - Export data to DEL (delimited ASCII), SQL or Parquet format
  - Import data from DEL, SQL or Parquet format
  - Customizable delimiters and format options
  - Secure password encryption (AES-256-GCM)
  - Message file logging
  - Multiple import modes (insert, insert_update, replace, create)
  - Parallel export/import with pipeline optimization
  - Column mapping for flexible data import
  - Smart JOIN detection for parallel export

Usage:
  imex [command]

Available Commands:
  encrypt     Encrypt password for secure automation
  export      Export data from MySQL/OceanBase
  help        Help about any command
  import      Import data into MySQL/OceanBase
  version     Print version information
